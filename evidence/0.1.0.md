# TypedMark 0.1.0 system exercise

Executed on 2026-10-30 with:

- TypedMarkSpecification `ba5bf5ce31e02d64ab9edc3b62dfafdeb1b40c8f`
- TypedMark adapter `c98f9ec797b1a3d67e8e59959229c241c60e2e84`
- TypedMarkExample `90e1581` (system files unchanged since; only the CI pins move)

The tracked files of the example were exported into a temporary source. That
source validated in `system_definition` mode with complete evaluation,
`valid: true`, and no findings, with `typedmark:queries`, `typedmark:systems`,
and `typedmark:views` required. The adapter then instantiated it as the working
collection `example-working-notes`.

Observed instantiated state:

- `typedmark.md` omitted the source `version` and `scaffold` fields;
- the caller-supplied collection name and description were used;
- publisher and license attribution and the three extension declarations were retained;
- `composition.sources` recorded `@developassion/typedmark-example` at `0.1.0`;
- the schema, template, and `notes` view were physically present under `.typedmark/`;
- `Notes/Welcome.md` was materialized from the scaffold;
- after the exported source was removed, a separate validation invocation over
  only the instantiated directory returned complete evaluation, `valid: true`,
  and no findings; and
- the `view` command printed the `notes` view of the instance as a one-row table
  (`Welcome`, `Notes/Welcome.md`), writing nothing.

Because this system intentionally has no `.typedmark/history.md`, migration
readiness from `0.0.1` to `0.1.0` returned `manual_resolution_required` and
exited 1. No migration was guessed or applied. The tracked example files were
unchanged by the exercise.

Commands, run from the directory that holds the three repositories' checkouts
and the exported `source`:

```sh
bun TypedMark/src/cli.ts validate source --schemas TypedMarkSpecification/schema/json-schema --mode system_definition
bun TypedMark/src/cli.ts instantiate source instance --name example-working-notes --description "Instantiated offline validation example." --schemas TypedMarkSpecification/schema/json-schema
rm -rf source
bun TypedMark/src/cli.ts validate instance --schemas TypedMarkSpecification/schema/json-schema --mode instantiated_collection
bun TypedMark/src/cli.ts view instance notes --schemas TypedMarkSpecification/schema/json-schema
bun TypedMark/src/cli.ts migration-readiness TypedMarkExample --from 0.0.1 --schemas TypedMarkSpecification/schema/json-schema
```
